# cloud-lab-01

Учебный проект: небольшое веб-приложение на Node.js с Express, запущенное в облачной среде GitHub Codespaces.

## Как запустить

```
npm install
npm start
```

После запуска сервер доступен на порту 3000 (меняется через переменную окружения PORT).

## Что умеет приложение

- `GET /` — стартовая страница
- `GET /api/status` — статус сервера: название приложения (задаётся переменной APP_NAME), время и hostname
- `GET /api/services` — список облачных сервисов
- `GET /api/services/:id` — сервис по номеру; если номера нет, отдаёт 404
- `POST /api/services` — добавление сервиса, тело: `{"name":"...","category":"..."}`; успех — 201, без обязательных полей — 400
- `GET /api/hello?name=Anna` — приветствие; если имя не указано, пишет «Гость»
